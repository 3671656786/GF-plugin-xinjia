# GF_mk 官方机器人插件

![版本](https://img.shields.io/badge/version-1.1.0-blue.svg)
![平台](https://img.shields.io/badge/platform-QQ%20Official%20Bot-green.svg)
![Node](https://img.shields.io/badge/node-%3E%3D18.0.0-brightgreen.svg)

**GF_mk** 是一款基于 QQ 官方机器人接口开发的多功能娱乐插件。集成了“星甲”文字放置游戏、每日签到与运势、音乐点播、超能力互动以及完整的 WebUI 后台管理系统。插件采用 Markdown 原生渲染与 Sharp 图片动态生成，完美兼容官方机器人的交互体验。

## 📦 版本信息
当前版本：**v1.1.0**
- 新增：回复消息自动添加蓝色 `@用户` 艾特（仅群聊/私聊文本消息）。
- 新增：底部附带“响应用时”提示，优化回复反馈体验。
- 修复：WebUI 后台手动发送消息时，不叠加艾特与耗时，保持消息纯净。

## ✨ 核心功能

### 1. 星甲系统（文字放置游戏）
- **装甲开号**：随机生成初始属性（火力、耐久、暴击、闪避）。
- **每日巡游**：签到获取星羽（货币）与经验，支持连签加成。
- **探索与战斗**：消耗耐久探索深渊，获取强化组件、血清等道具；支持随机挑战、匹配挑战。
- **联盟系统**：可加入四大联盟（以爆制爆、蚀月獠牙、暗域商锋、休闲至上），获取专属属性加成与联盟战奖励。
- **银行与商店**：存款生息（支持转账）、暗域商锋商店购买道具。
- **升级与转生**：满级后转生获取永久火力加成，冲击等级排行榜。
- **时空门**：在“深渊”与“芸界”之间传送，探索不同区域。

### 2. 签到与运势
- **每日打卡**：动态生成精美签到卡片，记录连签天数与积分。
- **今日运势**：抽签获取当日运势，生成专属运势图。
- **我的信息**：一键查看个人战绩、积分、道具库存、联盟归属等。

### 3. 音乐系统
- 支持 QQ、汽水、酷我、网易云四大音源点歌。
- 提供 Markdown 歌单列表，支持点击序号直接选歌。
- 支持个人收藏、播放收藏、取消收藏及清空歌单。

### 4. 今日超能力（互动玩法）
- 每日随机抽题，用户可点击“按下”或“不按”进行投票，查看全服投票比例。

### 5. 强大的 WebUI 后台
- **仪表盘**：查看群聊/私聊消息统计、活跃用户排行。
- **聊天记录**：按群组或用户查看历史消息，支持关键字搜索、消息撤回与置顶。
- **系统通知**：入群欢迎、退群提示、好友添加等系统事件通知。
- **Sharp 依赖管理**：后台一键检测、安装或更新 Sharp 环境。

## 🛠️ 安装与部署

### 前置要求
- Node.js >= 18.0.0
- 已配置好的 QQ 官方机器人框架（如 KKZ 等支持模块化插件的框架）。

### 安装步骤
1. 将插件文件夹放入框架的 `plugins` 目录下。
2. 确保插件根目录存在 `webui` 文件夹（内含 `remote.js` 前端模块）。
3. 在框架后台启用本插件。
4. **首次使用务必**：打开机器人后台 -> 找到本插件 -> 进入 **Sharp 依赖管理** 页面，点击 **一键安装 Sharp**。插件需要 Sharp 来渲染签到卡、运势卡和控制台图片。

### 依赖说明
插件依赖 `sharp` 进行图片渲染。若使用过程中提示图片渲染失败，请检查 `data/runtime-deps` 目录下是否安装成功，或通过 SSH 手动进入该目录执行 `npm install sharp`。

## 📁 数据目录说明

插件运行过程中会在 `data` 目录下生成以下文件：
- `data/tc/`：星甲游戏相关的所有数据（账号、联盟、道具、银行、签到记录等）。
- `data/今日运势/`：用户每日运势抽取记录。
- `data/默认资源/text/`：运势文案与图片URL配置。
- `data/默认资源/image/`：签到卡背景图、运势背景图等静态资源。
- `data/昵称记录/`：用户昵称缓存数据。
- `data/入群欢迎.json`：各群欢迎功能的开关配置。
- `data/chat-pins.json`：后台聊天记录置顶状态。
- `log/gf/`：系统消息日志，按日期和群聊/私聊分类存储的 `.jsonl` 文件。

## ⚙️ 配置项说明

在 `data/config.json` 中可配置以下选项（或在 WebUI 后台进行可视化修改）：
- `图片渲染`：是否开启图片渲染（默认 `true`）。
- `渲染模式`：图片渲染模式（`sharp` 或 `html`，默认 `sharp`）。
- `调试开关`：开启后只读模式运行，不写入数据（默认 `false`）。
- `系统通知openid`：系统事件（加群、退群等）通知到指定管理员 QQ 的 OpenID。

## 🧩 开发者指南

### 代码结构
- `index.mjs`：插件主入口，包含所有业务逻辑。
- `webui/remote.js`：WebUI 前端 React 模块。
- `lib/api/`：用于 B 站视频解析等外部 API 调用的模块。

### 渲染逻辑
所有图片渲染（签到卡、运势卡、星甲控制台）均采用 **SVG -> Sharp -> PNG** 的流程动态生成。图片生成后，会通过内置图床（58同城、pngcm、imgdd）上传至公网，再以 Markdown 图片格式发送给用户。

### 消息日志系统
消息记录采用 JSONL 格式按天存储，支持按群组、用户、关键字查询，并可通过 `markMessageRecalled` 标记撤回状态。
